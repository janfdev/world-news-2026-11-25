The world in one image — Wednesday 25 November 2026.

`main.py` (Python 3, standard library only) draws a one-page newspaper
front page of that day's world news and writes it to `/output/entry.png`
(or to `$MAKEFUN_OUTPUT_DIR/entry.png` when that variable is set). The
picture is rendered pixel by pixel from fixed data, so every run writes
exactly the same bytes.

The day's stories, as reported on 25 November 2026:

- The United States proposed new Section 301 tariffs on 14 trading
  partners over "excess factory capacity"; China faces a further 20%
  duty and rejects the charge, and Asian markets slid (Reuters).
- Ukrainian drones struck Russia's Samara region overnight, killing
  one; reports that oil refineries were hit are unverified (Reuters).
- China's Shenzhou-24 docked with the Tiangong station carrying
  Pakistan's first astronaut, the first foreign astronaut aboard
  Tiangong (Reuters, Xinhua).
- More than 2,100 migrants reached Spain's Canary Islands in a single
  day, a record (Reuters).
- A Sudanese rights group says RSF drone strikes killed civilians in
  Damazin; the toll is disputed (Reuters, AFP).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
